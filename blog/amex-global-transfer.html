1. Amex Global Transferとは？

Amex Global Transferとは、日本（または他の対象国）でAmexカードを持っている人が、そのクレジット履歴を使ってアメリカのAmexカードに申込める制度です。

アメリカでクレジットカードを作るには通常、アメリカ国内のクレジットヒストリーが必要です。しかしAmexはグローバルな金融機関として、母国でのAmexとの信頼関係を「橋渡し」として使うことを認めています。

🌏 Global Transferで何ができる？

日本のAmexカードを持っていれば、渡米直後でもクレヒスゼロ・SSNなしの状態でアメリカのAmexカードに申込める。しかもウェルカムボーナスも通常通り獲得可能なケースが多い。

2. なぜ渡米前にAmexを作るべきなのか

Global Transferには「対象国のAmexカードを最低3ヶ月以上保有していること」という条件があります。つまり渡米後に日本のAmexを作っても、すぐには使えません。

だからこそ渡米前に日本でAmexカードを作っておくことが重要なのです。渡米の3〜6ヶ月以上前に作っておけば、アメリカに着いた直後からGlobal Transferを使う資格ができます。

⚠️ 渡米後に気づいても遅い

渡米してからAmexを作ろうとしても、日本のAmexカードは日本の住所が必要なため作れません。日本にいる間に作っておくことが絶対条件です。

渡米前にAmexを作るメリット

  • 渡米直後からAmex Goldなどの高ポイントカードに申込める
  • クレヒスゼロ・SSNなしでも審査が通りやすい
  • JAL/ANA USAカードとの組み合わせで最強の初期布陣が組める
  • 食費4x（Amex Gold）を渡米初日から活用できる
  • MRポイントをANA・JALマイルに移行できる

3. 申込条件・必要なもの

申込条件

  • 日本発行のAmexカードを最低3ヶ月以上良好な状態で保有（6ヶ月以上が強く推奨）
  • アメリカの住所（自分・家族・知人の住所でOK。私書箱不可）
  • アメリカの電話番号（Google Voiceなどの無料サービスで取得可能）
  • パスポート（SSNの代わりに使用）
  • 年収（参考情報として聞かれる）

✅ SSNがなくても申込可能！

Global Transferの最大のメリットのひとつが、SSNなしでパスポートのみで申込めること。渡米直後でSSNがまだ発行されていない状態でも問題ありません。

4. 具体的な申込手順

1
americanexpress.com/en-us/company/about-us/moving-abroad/ にアクセス
「Global Card Transfer」のページ。申込みたいアメリカのAmexカードを選択する。
2
申込フォームでSSNの欄を「持っていない」を選択
SSNの横にある「ℹ️」ボタンをクリック → 「sign in for a simpler application process」を選択。ここがGlobal Transferへの入口。
3
日本のAmexアカウントでサインイン
日本のAmexのログイン情報（メールアドレス・パスワード）でサインイン。Amex USAが日本のアカウント情報へのアクセス許可を求めるので「Yes」を選択。
4
必要事項を入力
氏名・生年月日は自動入力される。アメリカの住所・電話番号・パスポート情報・年収を入力。
5
申込完了・審査結果を待つ
多くの場合、数日〜2週間以内に結果が届く。承認されると指定住所にカードが郵送される。
💡 電話申込も可能

オンラインで手続きがうまくいかない場合は、Amex USの新規アカウント専用番号に電話する方法もあります。電話口で「I am an existing American Express cardholder in Japan and I would like to apply for a U.S. card using the Global Transfer program」と伝えるとスムーズです。

7. よくある質問

Global TransferはMRポイントも移行できますか？
はい、日本のAmexで貯めたMRポイントをアメリカのAmexアカウントに移行できます。ただし為替レートが適用されるため、ポイント数が変わることがあります。移行前にAmexに確認することをおすすめします。
日本のAmexカードは渡米後も使い続けられますか？
住所変更が必要になりますが、基本的に継続使用できます。ただし日本の年会費が発生し続けるため、アメリカのAmexが手に入ったら解約を検討する方が多いです。解約のタイミングはGlobal Transfer申込から承認が出た後にすること。
Global TransferはChase Sapphireとどう組み合わせる？
Global TransferでAmex Goldを手に入れた後、6〜12ヶ月かけてクレヒスを積み上げてからChase Sapphire Preferredを申込むのがベストです。Amex Gold（食費4x）＋Chase Sapphire（旅行・外食3x）の組み合わせが在米日本人の最強布陣です。Chase 5/24ルールに注意しながら申込順序を計画しましょう。
渡米後に日本のAmexを解約したら？
Global Transferが完了してアメリカのカードを受け取った後なら、日本のカードを解約してもアメリカのカードには影響しません。ただし解約前にMRポイントの移行状況を確認しておきましょう。
Global Transferは必ず承認されますか？
承認率は高いですが、必ず通るわけではありません。日本でのAmex保有期間が長いほど、また良好な利用実績があるほど承認率が上がります。6ヶ月以上の保有を推奨する理由はここにあります。
